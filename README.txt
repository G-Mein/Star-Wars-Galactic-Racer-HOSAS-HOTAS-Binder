GALACTIC RACER HOSAS / HOTAS BRIDGE - v1.96
by JaffaQuake and Mars
===============================================

WHAT'S NEW IN v1.96
-------------------------
1. CLEAR MAPPINGS
   Every Learn row now has a Clear button. Clear removes the assignment immediately and saves
   Not assigned to the configuration.

2. CLEARER TRIGGER HELP
   Left Trigger / Right Trigger Learn rows are optional manual outputs. Normal analog acceleration
   and braking are already generated by Podracer Style / Traditional HOTAS control logic.

3. HOTAS AXIS DIAGNOSTICS MOVED
   Rx/Ry/Rz/Slider 1/Slider 2 live values now appear in the Live Input Monitor area instead of
   crowding the HOTAS configuration controls.

4. CLEANER MAPPING LAYOUT
   Increased the center gutter between the two button-mapping columns so each side reads clearly.

RETAINED
--------
- Auto / DirectInput / WinMM input backends and backend-aware Learn mappings.
- True DirectInput X/Y/Z, Rx/Ry/Rz, Slider 1/2 support.
- Podracer differential steering and Hybrid Preserve Thrust.
- Traditional HOTAS with Off / Digital at Idle / Analog Brake Zone braking.
- Optional HidHide setup helper.
- Resizable fixed-size canvas with working mouse-wheel/scrollbar scrolling.
- Pedal modes, keyboard camera controls and on-foot WASD mappings.
- 100/200/250/500/1000 Hz polling selection.
- ViGEm virtual Xbox output lifecycle and XInput diagnostics.
