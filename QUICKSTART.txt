GALACTIC RACER HOSAS/HOTAS BRIDGE v1.96 — QUICK START
by JaffaQuake and Mars

1. INSTALL
- Extract the ZIP and run Install.cmd.

2. CHOOSE INPUT API
- Auto: DirectInput first, with WinMM compatibility available.
- DirectInput: X/Y/Z, Rx/Ry/Rz, Slider 1/2 plus DirectInput button/POV learning.
- WinMM: original compatibility path and original button/POV learning.

3. CHOOSE CONTROL MODE
Podracer Style
- Choose left/right controls and axes, or use Detect Left/Right.
- Optional Hybrid Preserve Thrust.

Traditional HOTAS
- Choose throttle + axis and flight stick + X/Y axes.
- Choose Brake Behavior: Off, Digital at Idle, or Analog Brake Zone.
- With DirectInput/Auto selected, Rx/Ry/Rz/Slider diagnostics appear in LIVE INPUT MONITOR.

4. LEARN / CLEAR BUTTONS
- Click Learn, then press the controller button/hat/switch to assign.
- Click Clear to remove an assignment immediately.
- Left Trigger and Right Trigger Learn rows are OPTIONAL manual overrides; analog controls already
  generate normal acceleration/braking.

5. OPTIONAL HIDHIDE
- Use HidHide Setup if the game also sees raw physical controllers and causes double input.

6. OUTPUT
- Click Initiate Xbox Controller to create the virtual Xbox pad.
- Click Deactivate Xbox Controller when finished.
